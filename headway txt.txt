Grammar reference
4.1 Possessive adjectives
This is my/your/his/her/our/their family, school, office.
4.2 Possessive 's
's shows possession. This is John. This is his bike. → This is John's bike. This is Marie. This is her car. → This is Marie's car. Kelly and Tim are married. This is their son. → This is Kelly and Tim's son. his house → Noel's house her name daughter → your wife's name daughter Pam and Bob's daughter
's is also the short form of is. he's = he is she's = she is it's = it is Who's = Who is
4.3 Common verbs
I/You/We/They like football. He/She likes football. I/You/We/They work in an office. He/She works in an office.
Have is an irregular verb. I/You/We/They have a good job. He/She has a laptop.

➜12.1 would like

➜12.2 some and any
1 We use some in positive sentences.
I'd like some ham. There's some cheese. We have some books.
2 We use any in questions.
Is there any ham? Do you have any money? Are there any people?
3 We use any in negatives.
There isn't any bread. We don't have any friends. There aren't any books.
4 We use some when we offer things or ask for things.
Would you like some wine? Can I have some like cheese?
➜12.3 like and would like
1 We use like (like doing) to talk about things we always like.
I like coffee. (= I always enjoy coffee.) She likes swimming. (= She always enjoys swimming.)
2 We use would like to talk about things we want now or soon.
I'd like a coffee. (= I want a coffee now or soon.) I'd like to go shopping. (= I want to go shopping.)
